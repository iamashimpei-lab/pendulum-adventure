# 設計段階の敵対的レビュー (Sol / gpt-5.6-sol, reasoning high) — 2026-08-09

対象: docs/game-design.md v1。裁定結果は v2 に反映済み (全 findings 受入。P0-5 のリプレイ再生検査のみ拡張段階へ先送り)。

**注記 (2026-08-09 晋平さんの指摘による精密化)**: P0-1 の「支点をゆっくり引き離すだけで高得点」という表現は物理として不正確。支点を等速で動かすだけでは玉が追従し、ゴムは重力でぶら下がる分しか伸びない。実際に成立する悪用経路は ①壊れない障害物に玉を押し当てたまま支点を反対側へ引き離す (ゆっくりでも伸びが増える) ②接触の直前に支点を素早く引き、当たる瞬間だけ伸びを大きくする、の 2 つ。修正案 (得点倍率に衝突速度の下限を要求) はこの 2 経路を塞ぐものとして有効なので、裁定は維持。

## 結論

現状は「手触り試作には進めるが、ステージ量産・経済実装には進めない」という条件付き No-Go です。

企画書の 5 本柱は強く、企画の核として妥当です。一方で、現在の仕様では「深く伸ばして得点する」よりも「安全強化を重ねる」「支点をゆっくり引っ張る」「範囲攻撃でまとめて壊す」方が有利になる可能性があります。

## パワーアップでゲームが壊れる具体経路 (4 本)

1. **Easy + 長いゴム + 修復の重ね掛け**: 限界 +30% と +10% が重なり、復活最大 4 回・時間無制限で危険管理なしの試行回数突破が可能に。→ 物理限界を難易度で変えず、得点は装備ごとの切断限界に対する正規化伸び率で計算。修復回数は一元管理
2. **大玉 + 貫通 + 爆発で自動コンボ**: 二次破壊までコンボ・倍率・かけらに数えると、一度の安全な接触でステージと経済を同時攻略できる。→ 玉は排他装備、二次破壊はコンボ延長なし・倍率低下・必須スイッチに作用しない
3. **Hard の短いステージ周回**: 1.5 倍通貨の反復で恒久強化を早期取得し、後半 Hard を強化で圧倒する自己破壊ループ。→ Hard 報酬は初回達成・装飾・記録へ。性能通貨の反復倍率をなくす
4. **重い鉄球の無料火力**: 切断が伸び量だけなら同じ危険度で衝突エネルギーだけ増える。→ 切断表示は共通の正規化伸び率、重球は「溜めが遅い・方向転換が難しい」の交換条件

## 操作方式と画面向きの推奨

- **(a) 直接操作を推奨**: 支点を接触点の上方約 56〜72 CSS px に置き、指から支点まで短い半透明の線で接続。オフセットはわずかに画面中央方向へ傾け、重要な的を接触点直下へ置かない配置規則。(b) 相対タッチパッドは大型 iPad 向けの任意設定
- 比較試作の計測項目: 初回命中までの秒数 / 30 秒中の意図しない指離れ / 3 個命中成功率 / 子どもが画面でなく指を見ている時間
- **横向きを推奨**: 左右に育つ振り子軌道、外周 = 危険・内周 = 安全の同時提示、両手保持 + 片指操作。左右どちらの横向きにも対応、縦向き時は回転する端末の絵を表示。iPhone 横長と iPad 4:3 でプレイ領域を別々に検証、画面端一指分に必須目標を置かない

## もっと面白くする任意案 (3 件とも v2 に採用)

1. **二重の星座ルート**: 内側に安全で低得点の的、外側に危険で高得点の的を振り子軌道に沿って配置。同じステージで子どもは安全ルート、大人は危険ルートを選べる
2. **コンボが音楽になる**: 直接ヒットごとに打楽器・低音・旋律が追加、伸び率が高いほど音が華やかに。柱 4 と 5 を同時強化
3. **プレイヤーが開けるボス**: 左右の留め具を連続で打つと装甲がめくれる。危険な外側の留め具ほど長く開く
