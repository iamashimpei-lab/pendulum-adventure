# ふりこの大冒険 (仮題) — ゲーム企画書 v2

作成: 2026-08-09 / v2: Sol 敵対的レビュー (P0×5 / P1×10 / P2×3、全件受入) を反映。レビュー全文と裁定 = [design-review-sol-2026-08-09.md](design-review-sol-2026-08-09.md) / 状態: 手触り試作の実装待ち

## 1. コンセプト

- Windows フリーゲーム「Pendulumania」(2000 年、振り子スコアアタック型アクション) の物理の快感を土台に、冒険ステージ進行とパワーアップ経済を足した子ども向けアクションゲーム
- 対象: 小学生の子ども + 大人 (家族で遊ぶ)
- 動作形態: 単一 HTML ファイル。iPhone / iPad の Safari 系環境で動く。App Store 配布はしない
- 操作は指 1 本。文字が読めなくても遊べる画面設計

## 2. 継承する 5 本柱 (壊してはいけない)

1. **操作は間接・1 系統**: 触れるのは支点だけ。重りはゴムひもの物理で追従する
2. **リスクとリターンの同居**: ゴムの伸び = 得点倍率 = 切断危険、が 1 変数に同居
3. **勢いを育てて放つ**: 何往復も揺らしてタメたエネルギーを叩き込むリズム
4. **コンボ**: 勢いを殺さず繋ぎ続ける流れへの報酬
5. **音と光**: 物理の快感を演出で倍加する。開発の後回しにしない

## 3. 操作仕様 (確定・2026-08-09 実機テストで原作準拠に改訂)

- **支点 = ポインタ位置に完全一致 (遅れ・速度制限なし)**。原作 Pendulumania は「マウスを動かすだけで輪っか (支点) がカーソルに付いてくる」操作。支点に平滑化や速度・加速度制限を入れると「ポインタ→支点→玉」の二重操作になり、著しく難しくなる (実機テストで確認)。唯一の間接性は支点→玉のゴムだけに保つ
- **PC (マウス)**: ボタンを押さずにカーソルを動かすだけで支点が追従する。オフセットなし (支点 = カーソル)。最初の 1 クリックだけは開始 + 音声再生の解禁に使う
- **タッチ (iPhone/iPad)**: 指に追従。玉が指で隠れないよう支点を指の**上 56〜72 CSS px** にオフセット (これは固定の平行移動であり遅れではない)。指と支点を短い線で結ぶ
- **入力喪失で一時停止**: 指を離す/マウスが画面外へ出る/電話・通知で全停止。再開時に支点をワープさせない。停止表示は 0.28 秒の猶予後に出す (連続プレイ中の点滅防止)
- 画面向き: **横持ち** (左右どちらも対応)。縦持ち時は文字でなく「回す端末の絵」を表示
- 配置規則: 重要な的を接触点の真下・画面端 (指 1 本分) に置かない
- 撤回した対策: 「支点の速度・加速度上限」(旧 P0-2) は二重操作を生むため撤回。高速フリックでの過大エネルギー投入は原作にもある「伸ばし技術」の範疇として許容し、代わりに切断の猶予時間と減衰で暴れを抑える

## 4. ゲームの流れとステージ構造

- ワールドマップ → ステージ → リザルト (星のかけら) → 工房 (強化・試し振り) → 次のステージ
- 試作段階ではマップ・図鑑・価格表を作らず、**ステージ選択 + 工房 (動くプレビューとその場試し振り)** のみ
- **1 ステージ = 30〜45 秒の区画 2〜4 個**。ゴム切断時は区画の頭からやり直し (コンボと区画スコアだけ失う。ステージ全体はやり直させない)
- 初期版は 1 画面固定 (スクロールなし)
- クリア条件 3 型: 的を全部壊す / ゴールゲートを開く / ボスを倒す
- **時間制限は置かない**。タイムは任意の記録扱い

## 5. コアの数式 (骨格として確定)

- **伸び率** = (現在長 − 自然長) / (切断長 − 自然長)。0〜1 に正規化し、全ての玉・全難易度で共通
- **破壊力 = 得点倍率 = 衝突時の伸び率**。速度は破壊可否にも倍率にも使わない。通常の的は接触すれば必ず破壊し、得点 = 100 × (1 + 3 × 接触時伸び率)
- **接触判定** = 高速移動だけでなく、固定刻みの始点ですでに的の当たり円内にいる場合もその場で命中とする。通常の的は命中した固定刻みで消えるため、多重ダメージ防止の接触状態は持たない
- **かくれる的** = 殻の間は当たり判定ごと消え、玉は殻をすり抜ける。出ている間は通常の的と同じく接触すれば必ず破壊する
- **コンボ** = 直接ヒットで更新、約 2 秒以内 (1.5〜2.5 秒で実測調整) の次の直接ヒットで継続。時間窓の終了・切断で終了。輪が縮む表示 + 音階上昇で文字なし表現。爆発の巻き込みはコンボを増やさない、貫通は 1 振りにつき 1 更新まで
- **切断** = 伸び率 1.0 を 0.12 秒超え続けたとき。瞬間のスパイクでは切れない (2026-08-09 の実プレイ「すぐ切れて難しすぎる」を受けて超過時間方式に決定)

## 6. ギミックカタログ v2 (Sol 判定を反映)

**採用**:
1. 動く的 / 隠れる的 — 一定周期のみ (ランダム移動禁止)、出現前に振動・影の予兆。隠れている間は当たり判定がなく、出ている間は接触で必ず壊れる
2. 水ゾーン — 泡と減速で伝わる。1 画面の一部に限定
3. 連鎖スイッチ — 「打つと次が光る」形のみ。色の順番暗記はさせない
4. ボス — **留め具を打つと装甲がめくれる「自分で開ける」型**。外側の危険な留め具ほど長く開く (時間待ち式は不採用)

**不採用・格下げ**:
- ハサミ虫 — 伸びと無関係な即死は理不尽 (「危険帯のゴムだけ予告後に切る」形なら将来再検討)
- 運び玉 — 振り回す快感を封じる作業になる。任意ボーナスのみ
- 風・低重力 — 操作ミスに見えやすい。ワールド 2 以降で再検討

**導入原則**: 新ギミックは 1 ステージに 1 種類ずつ。初出は必ず安全な教材配置から
**レベルデザイン原則 (二重ルート)**: 内側 = 安全で低得点、外側 = 危険で高得点の的を振り子軌道に沿って配置。同じステージを子どもは安全に、大人は危険に遊べる

## 7. 難易度 Easy / Normal / Hard (v2: 物理を変えない)

- **物理と切断限界は全難易度で共通** (Easy で覚えた振り方がそのまま Normal で通用する)
- Easy: 危険帯でスローモーション + 強い警告 + 区画復活 3 回
- Normal: 区画復活 1 回
- Hard: 復活なし + 追加目標 (的の速度は一律には上げない)
- いつでも変更可能、ステージ単位
- **難易度報酬は初回クリアの星・称号・かざりに限定**。かけら (性能通貨) の獲得率は難易度で変えない (Hard 周回の稼ぎ壊れ防止)。初回失敗にも少量の保証あり

## 8. パワーアップ経済 v2

### 通貨「星のかけら」

1. ステージクリア時にスコアから換算 (深伸ばし・コンボが多いほど多い)
2. ステージ内配置のかけらを拾う (危険な場所ほど多い)。再訪時の復活量と価格は上限付きで設計

### 強化 3 系統

- **玉 = 排他装備 (重ね掛けなし・付け替え無料)**: おおきな玉 (当たり判定拡大・威力低め) / つらぬき玉 (勢いがあると貫通) / はじけ玉 (深伸ばしヒットで周囲を巻き込む) / 鉄球 (威力大・立ち上がりが遅くコンボ困難) / 羽玉 (威力小・軌道修正しやすい)。各玉に明確な不利を持たせ、初期玉で全ステージ攻略可能
- **爆発・貫通の巻き込み破壊は**: 低得点 + コンボ延長なし + 必須スイッチには効かない (自動コンボ化の防止)
- **ゴム**: ながいゴム (切断長 +10%。得点は正規化伸び率なので「安全を買うと最高倍率も遠くなる」が自動で成立) / ひかるゴム (危険帯を色・音・形で強調) / おまもり結び (区画復活 +1)。**復活回数は難易度分と一元管理、合計上限 3** (重ね掛けで切断が無意味になるのを防ぐ)
- **かざり**: 玉の見た目・軌跡・ヒット音の楽器替え。性能に影響しない収集要素、図鑑つき。一番安くして買い物の楽しさを最初に体験させる

### 原則 3 つ (v2 改訂)

1. 柱 2 をお金で消させない (「絶対切れないゴム」は売らない)
2. 数字ではなく手触りを売る (見た目・音・挙動が変わる強化のみ)
3. **本編は初期装備で全クリア可能**。強化は近道・追加かけら・スコア目標のためで、必須経路の入場料にしない

### ループを回す仕掛け

- 見せ場設計: 強化を買える時期の直後に、その強化が輝く配置を置く (必須経路ではなくボーナスとして)
- 詰まりの逃げ道: 前のステージの遊び直しで必ずかけらが貯まる
- 危険警告は**色 + 音 + 形 (ゴムの太さ・震え・火花・支点の脈動) の多重表現** (消音中・色覚差・騒がしい環境でも 1 系統で伝わる)

## 9. ステージ出荷条件 (品質ゲート)

- 各必須配置に「何を教える / 試す配置か」を 1 行付ける。説明できない配置は削除
- 作者が iPhone 横長・iPad 4:3 の両方で、無強化 Normal を 3 連続クリア
- 説明なしの子どもが 3 試行中 2 回クリア
- 必須物を画面端・指の真下に置かない
- **AI は配置候補の生成まで。最終座標は人間の実機テストで確定**
- (拡張段階で導入) 成功リプレイを保存し、物理を変更したら再生して全ステージ検査

## 10. 技術方針 v2

- 単一 HTML ファイル: Canvas 2D + Web Audio API。外部ライブラリ・外部通信なし、オフラインで動く
- **物理は固定刻み + 最大サブステップ数** (描画は可変)。高速の玉はスイープ衝突判定 (壁抜け防止)。入力は時刻付きで補間
- 内部描画解像度に上限。粒子・軌跡・同時発音数に予算を持ち、フレーム落ち時は演出から段階的に削る
- セーブ: localStorage (強化・進行度)。配布方法は §11 で確定
- 画像: 基本は Canvas 描画 (ベクター調)。タイトル絵・キャラ絵など少数のみ gpt-image-2 (codex `$imagegen`) で生成して base64 埋め込み (枠消費が重いため大量生成しない)
- 音: Web Audio で合成 (外部音声ファイルなし)。コンボで打楽器→低音→旋律が積み上がり、伸び率が高いほど音が華やかになる設計 (柱 4 × 柱 5)

## 11. 配布・プレイ方法 (推奨確定)

- **本番: GitHub Pages で配信 + Safari で開いて「ホーム画面に追加」**
  - 全画面で遊べる (Safari の端スワイプ「戻る」誤爆がない = アクションゲームに重要)
  - セーブ (localStorage) が安定して残る
  - 更新は git push だけ。子どもの端末はアイコンを開けば常に最新版
- 開発中の素早い確認: 現行の Sitecase 方式で可。ただしビューアーアプリ内のセーブ永続性はアプリ実装次第 (未検証) なので、本番プレイはホーム画面版に寄せる
- Safari で素のまま遊ぶのは非推奨: 端スワイプ誤爆 + 長期間開かないとセーブが消されることがある

## 12. 開発の進め方 v2

0. **縦切り試作 (最優先)**: 30〜45 秒 × 1 区画。「基本の的 3 個 → 危険な外側の的 1 個 → 切断」だけ。確認するのは 2 点 = 振り回して気持ちいいか / 子どもが「もう 1 回」と言うか。ここで手触りが出なければ経済・ステージに進まない
1. **ワールド 1**: 3 ステージ (区画 6〜9 個) + 玉 2 種 + ゴム 2 種 + 難易度 3 段 + セーブ + 工房 (試し振り付き)
2. **拡張**: ワールド 2〜3、ボス、かざり図鑑、リプレイ再生検査

各段階で iPhone + iPad の実機確認 → 子どもたちのテストプレイ。実装完了後に Sol の敵対的レビュー第 2 回 (実プレイ所感込み)。
